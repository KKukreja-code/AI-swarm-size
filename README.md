# AI-swarm-size
Repo for Research Impact Oxford project quantifying swarm capabilities in terms of compute allocations and coordination efficiency. This contains statistical analyses and forecasts for key variables informing our model.

The two main files so far look at:
- The parameter lambda, which measures how performance scales with the number of agents. This captures the coordination overhead (or potentially synergy) of introducing more agents into a swarm.
- Compute stock forecasts based on data from Epoch AI, which will allow us to infer inference compute allocations for deployed swarms.
